# ryoiki-tenkai（領域展開）

[English](README.en.md) ｜ 繁體中文

給 AI agent 用的技能：在動手之前，先把一個點子、任務或產業**展開**，再收斂成可以執行的計畫。名字取自《咒術迴戰》的「領域展開」（Ryōiki Tenkai）。

流程整理自 Felix Rieseberg〈How to be more ambitious: A tutorial for humans with models〉的四個面向：高度、深度、廣度、外部裁判。順序固定是**先發散、再收斂**，而且允許結論改掉原本的題目。

## 它做什麼

八個步驟，最後產出一份檔案和一段 YAML 摘要：

| 步驟 | 內容 |
|---|---|
| 1. 拉高高度 | 連問三次「做完之後真正想要發生什麼」，寫出原版、拉高一層、極致版，推薦一個 |
| 2. 改用動詞描述 | 把「報告」「App」這類名詞換成這件事實際在做的 3–5 個動作 |
| 3. 發散方向 | 跨領域、反過來、換對象、換位置、AI 演進、不合理目標，各提 1–2 個方向 |
| 4. 組專家團隊 | 5–7 個專業，至少 2 個是領域內想不到的，一定有紅隊 |
| 5. 挑戰假設 | 列出沒說出口的假設，標出最脆弱的 3 條和最便宜的推翻方法 |
| 6. 外部裁判 | 可執行的檢查、真實世界的資料、真人；不准用「AI 自己評分」 |
| 7. 收斂 | 評分選出主方向和大膽押注，拆成工作線，寫最先做的 3 件事和喊停條件 |
| 8. 重寫指令 | 把原任務改寫成更有野心、可以直接交給 agent 的指令 |

規則重點：不要角色扮演；每個判斷標示〔事實〕〔推估〕〔待查〕；不准只給「更快做同一件事」的建議；換個領域還能照用的句子要刪掉重寫。

## 三種用法

| 你說 | agent 會做 |
|---|---|
| 「領域展開」＋題目 | 跑完整八步，寫成 `docs/expansion-<短名>-<日期>.md`，回覆只給摘要 |
| 「快速展開」「精簡版」 | 在對話裡回答四個問題，再重寫指令 |
| 「給我 prompt」 | 給 `prompt.md` 的內容，讓你貼給別的模型或 agent |

## 安裝

### Claude Code

```bash
git clone https://github.com/ailazytech/ryoiki-tenkai.git ~/.claude/skills/ryoiki-tenkai
```

重開 session 後，說「領域展開」「ryoiki tenkai」「野心不夠」「方向卡住」都會觸發。

### 其他 agent 或模型

支援 `SKILL.md` 的 agent：把資料夾放到它的技能目錄。不支援的：直接貼 `prompt.md` 裡的完整版或精簡版 prompt。

## 檔案

- `SKILL.md`：給 agent 讀的技能說明（八步、規則、輸出格式）
- `prompt.md`：可以直接貼上的 prompt（完整版、精簡版）
